# شوكة وملعقة — كتاب الطبخ المصوّر

موقع عربي باتجاه RTL، يحافظ على الرسوم والوصفات الخمس والثلاثين.

## الصفحات

- `index.html`: اختيار الوصفات فقط؛ جميع الوصفات ظاهرة حسب الوجبة، وكل بطاقة تفتح صفحة مستقلة.
- `recipes/recipe-ID.html`: وصفة واحدة بكل مكوّناتها ومقادير الحصص وخطواتها المصوّرة. تشمل تحديد المكوّنات، الطباعة وحفظ PDF، والعودة للفهرس والتنقل بين الوصفات.
- `kitchen.html`: دفتر المطبخ ودليل الحفظ والمصادر.

## التطوير

- `source/book.json`: المصدر الحالي لبيانات الوصفات والدليل. عدّل المحتوى هنا.
- `scripts/build.py`: قوالب الصفحات وتوليد الموقع.
- `assets/styles.css`: التصميم المتجاوب وتنسيق الطباعة.
- `assets/app.js`: تحديد فصل الوجبة الحالي أثناء التصفح وانتظار تحميل صور الوصفة قبل الطباعة. تحديد المكوّنات مؤقت داخل الصفحة ولا يحتاج إلى تخزين.
- `assets/`: الصور المشتركة؛ لا تُحذف عند نقل الموقع.

لإعادة البناء والتحقق:

```sh
python3 scripts/build.py
python3 scripts/check.py
node --check assets/app.js
```

افتح `index.html` مباشرة، أو شغّل `python3 -m http.server 8000` داخل المجلد وافتح `http://localhost:8000`.
الموقع ثابت ويعمل دون قاعدة بيانات أو اعتماد على خدمات خارجية. محتوى الصفحات وروابطها يعمل دون JavaScript.

## اتجاه المشروع

الفهرس مخصّص لاختيار الوصفة، والتفاصيل في صفحات مستقلة. نحافظ على الهوية العربية والرسوم والألوان وكل الوصفات دون فلاتر تخفيها. تعديل المحتوى يتم في مصدر البيانات، والتصميم في ملف CSS المشترك. مراجعة إخراج PDF والشاشات المختلفة هي الخطوة التالية قبل النشر.

## المواد الأصلية

- `source/book-template.html`: أرشيف النسخة الأصلية المستقلة بالصور؛ لم يعد مصدر البناء.
- `assets-original/` و`Cooking-Illustrations-PNG.zip`: الرسوم الأصلية.
- `Weekly_Meal_Cards.pdf`: نسخة PDF مرجعية سابقة.

## الهوية الجديدة والصور

تمت إعادة تصميم الصفحات كدفتر طبخ دافئ: عناوين بخط Noto Naskh Arabic، ونصوص بخط IBM Plex Sans Arabic؛ الخطّان محليان ومرخّصان وفق OFL. الواجهة بلون الورق العسلي والأخضر الداكن ولمسات الطين، مع ترحيب مصوّر بإطار مقوّس، وفصول للوجبات وشبكات وصفات مفتوحة. صفحات الطبخ تضم ورقة مكوّنات قابلة للتحديد وخطوات كبيرة مرقّمة. تفاصيل الاتجاه في `DESIGN.md`. الفهرس لا يزال المكان لاختيار الوصفات، وكل وصفة تفتح صفحة مستقلة.

- الصور الأصلية المولّدة محفوظة في `assets/visuals/` دون تعديل.
- نسخ الموقع المضغوطة في `assets/web-visuals/`؛ لتحديثها بعد إضافة صور جديدة شغّل `python3 scripts/prepare-visuals.py` (يتطلب cwebp)، ثم أعد البناء.
- يختار البناء الصور الجديدة الموجودة تلقائيًا، ويحتفظ بالصورة القديمة للمسارات التي لم تُولّد بعد. بيانات الوصفات الأصلية في `source/book.json` محفوظة.
- تُستثنى مؤقتًا ثلاث صور تحتاج تصحيحًا: `site/breakfast.png` و`recipes/11/step-03.png` و`recipes/27/step-05.png`؛ القائمة في `scripts/build.py`.
- تشمل الصفحات 208 رسومات مولّدة مرتبطة مباشرة، مع خامات ورقية وغصن زخرفي. بقية الملفات تشمل مراجع الشخصية وخامات ومواد محفوظة لا يلزم عرضها جميعًا.
